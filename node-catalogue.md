# Complete skill catalogue

Draft prices in Emeralds. Effects are cumulative totals at the purchased rank, not additional bonuses to add repeatedly. All skills persist across rebirths.

## Starting purchase

First Harvest — +5% normal-mob loot; 25 Emeralds. Starts unowned and reveals the five starter paths.

## Combat

- Requires: First Harvest rank 1.

- Rank 2/5: **+10% selling throughput** — 400 Emeralds; rebirth 0.

- Rank 5/5: **+25% selling throughput** — 100,000,000 Emeralds; rebirth 2.

### Fair Value (`value`)

- Requires: Fast Counters rank 1.

### Full House (`village`)

- Requires: Busy Counters rank 2.
- Baseline: Stands split the base drain.
